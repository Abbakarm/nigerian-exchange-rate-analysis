# Contributing to Nigerian Exchange Rate Analysis 🇳🇬

First off, thank you for considering contributing to this project! It is contributions like yours that help us understand the Nigerian economic landscape better.

### 🛠 How Can I Contribute?

#### Reporting Bugs
- Open an issue and describe the bug.
- Include a screenshot of the error if possible.
- Tell us which version of Python you are using.

#### Suggesting Enhancements
- If you have an idea for a new feature (like a new data source or a new visualization), please open an issue first to discuss it.

#### Pull Requests
1. Fork the repository.
2. Create a new branch: `git checkout -b feature-your-feature-name`.
3. Make your changes and commit them with a descriptive message.
4. Push to your fork and submit a Pull Request.

### 📋 Technical Standards
- **Python Version:** 3.8 or higher is recommended.
- **Dependencies:** Please document any new libraries you add (e.g., `requests`, `pandas`).
- **Data Integrity:** Ensure that exchange rate data remains accurate and follows the CBN format.

### 🤝 Code of Conduct
We are committed to providing a welcoming and inclusive environment. Please be respectful to all contributors.
